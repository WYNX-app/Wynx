# WYNX — Contexto do Projeto

## Produto
Plataforma de gestão inteligente de estoque para MEIs e pequenas empresas.

## Slogan
Transformando o controle de estoque em inteligência para o seu negócio.

## Equipe
- Heitor — CEO/fundador, desenvolvimento
- Enzo — Co-CEO, marketing
- Lara — Designer, UX/UI

## Stack
- React + TypeScript + Vite
- Tailwind CSS v4
- Supabase (PostgreSQL, Auth, Storage, RLS)
- Electron (atual) / Tauri (futuro)

## Regras
1. Toda tabela de negócio tem company_id e RLS.
2. Segredos nunca no cliente.
3. Movimentação sempre registrada no histórico.
4. IA nunca inventa números — só explica dados.
